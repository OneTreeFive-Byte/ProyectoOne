# Mi Sitio Web

Este es un proyecto web básico con HTML semántico, CSS estilizado y diseño responsivo.

## Funcionalidades

- Estructura HTML semántica (header, nav, main, section, footer)
- Formulario de contacto con Formspree
- Estilos CSS con Google Fonts y fondos personalizados
- Diseño responsivo con Flexbox y Grid
- Contenido multimedia integrado
- Navegación interna
